Mode: Operate. User approved the atlas direction and code-first workflow.

## Direction contract

THESIS: Make real ownership and activity readable across a project's worktrees. A graph is the main working surface; evidence and unknown states remain visible.

OWN-WORLD: Ink-blue navigation, a pale cool canvas, white node surfaces, blue selection, teal activity, amber waiting and red failure. Use a system UI typeface with tabular data. Compact nodes and aligned panel rows provide density without tiny text.

STORY: Select a project, trace orchestrator to worktrees and agents, select a node for its observed status and recent output, inspect GitHub PRs and history alongside work.

FIRST VIEWPORT: A narrow left project rail, central graph occupying most width, fixed right inspector with GitHub/activity tabs. The header shows selected project and synchronization freshness. The signature move is a short traveling signal on active graph connections; reduced motion holds a static highlighted path. On narrow screens the inspector follows the graph and no controls disappear.
