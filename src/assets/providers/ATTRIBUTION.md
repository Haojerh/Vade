# Provider Assets Attribution & Provenance

The shared ProviderIcon component now mirrors Orca's glyph rendering and bundled assets. Current sources, pinned revision, and license are recorded in [orca/ATTRIBUTION.md](orca/ATTRIBUTION.md). The original standalone SVG files listed below are retained as legacy assets.

## 1. Codex / OpenAI
- **File**: `codex.svg`
- **Vendor**: OpenAI, Inc.
- **Source**: OpenAI Official Brand Guidelines & Official Vector Specifications (`https://openai.com/brand/`)
- **Description**: Official OpenAI looped rosette/knot vector symbol.
- **Usage**: Scoped observational identification of Codex/OpenAI agent runners in Orca Live Dashboard.

## 2. Google Antigravity
- **File**: `antigravity.svg`
- **Vendor**: Google LLC
- **Source**: Google Antigravity Official Press & Brand Assets (`https://antigravity.google/press`, `https://antigravity.google/favicon.svg`)
- **Description**: Official Google Antigravity symbol with iconic gravity-well arch geometry.
- **Usage**: Scoped observational identification of Antigravity agent runners in Orca Live Dashboard.

## 3. Claude / Anthropic
- **File**: `claude.svg`
- **Vendor**: Anthropic, PBC
- **Source**: Claude Official Web Application Asset (`https://claude.com/`)
- **Description**: Official Anthropic sunburst / spark symbol with terracotta accent.
- **Usage**: Scoped observational identification of Claude agent runners in Orca Live Dashboard.

## 4. OpenCode
- **File**: `opencode.svg`
- **Vendor**: Anomaly Co.
- **Source**: OpenCode Official Repository Identity (`https://github.com/anomalyco/opencode/blob/v2/packages/identity/mark.svg`, `https://opencode.ai/brand`)
- **Description**: Official OpenCode square block mark.
- **Usage**: Scoped observational identification of OpenCode agent runners in Orca Live Dashboard.

## 5. Kilo Code
- **File**: `kilo.svg`
- **Vendor**: Kilo Code / Kilo-Org
- **Source**: Kilo Official Brand Assets (`https://kilo.ai/favicon/favicon.svg`, `https://github.com/Kilo-Org/kilocode`)
- **Description**: Official Kilo Code geometric block mark.

## 6. CodeBuddy
- **File**: `codebuddy.svg`
- **Source**: User-provided CodeBuddy SVG (Lobe Icons markup), supplied in this implementation request.
- **Usage**: Provider identification throughout the shared ProviderIcon component. Original paths, colors and gradient are preserved; the gradient ID is scoped to the standalone SVG.
