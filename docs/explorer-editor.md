# Explorer and editor

The standalone file APIs accept only a registered project and discovered worktree ID. File paths are relative, bounded, checked component by component and cannot resolve through symlinks, outside the worktree, into Git metadata or Vade's private registry. Reads are bounded UTF-8 text; saves compare the current byte hash immediately before atomic replacement and return the hash of the bytes just written. An uncertain save is never retried automatically. Fixed app-opening targets cannot carry executables or flags from HTTP.

Binary reads now return a read-only preview descriptor. Supported raster images up to 2 MiB are shown inline; unsupported formats and larger files get a centered explanation, size and Reveal action. Binary saves remain rejected. Browser previews use a sandbox CSP with scripts, external resources and application-origin privileges disabled.

Explorer row and background context menus reuse the shared ContextMenu, Modal and confirmation controls. They support new files/folders, scoped in-app copy/paste, absolute/relative path copying, duplicate, view, Git changes, read-only browser preview, reveal, rename and recoverable deletion. `runtime/workspaceActions.ts` validates discovered paths and fresh bounded fingerprints (2,000 entries, 32 MiB, five-second scans). Copy and file rename refuse occupied destinations. Delete moves an item to private Vade Trash; Undo restores it to an unoccupied original path. Trash is bounded to 200 items and cross-volume moves fail without removing the source. No Git staging, commits or shell input is accepted. File path copy uses the browser clipboard; file Copy/Paste is scoped to the selected Explorer worktree.

Context-menu reference: Orca's [row menu](https://github.com/stablyai/orca/blob/main/src/renderer/src/components/right-sidebar/file-explorer-row-context-menu.tsx) and [background menu](https://github.com/stablyai/orca/blob/main/src/renderer/src/components/right-sidebar/use-file-explorer-background-menu.ts), adapted to Vade's existing components and owned workspace APIs.

Menus prefer the left side of their click anchor, use compact nonwrapping rows and close through the shared 150 ms dismissal lifecycle. Renaming edits the filename inline in both search modes. Copy notices dismiss automatically with reduced-motion-aware transitions; recent Trash restores remain available from Undo Last Delete after the notice disappears. Raster previews include pointer-anchored zoom, fit/reset, dimensions, byte size and MIME metadata. Windows browser Reveal requests use the host Explorer selection action.

General settings choose Chat or Terminal for newly opened agent overlays. Chat displays observed working intervals and retains their total at completion, interruption or failure. Waiting time is excluded; partial observations are labeled and clocks do not reconstruct historical work after a backend restart.

An empty Chat composer presents Stop during observed live working activity. `POST /api/projects/:projectId/nodes/:nodeId/interrupt` accepts only `{}` and sends fixed native interruption keys through the owned-terminal input path after checking the exact live launch and current working status. OpenCode v1/v2 and Kilo require two Escapes: the action sends the first, waits up to 1.8 seconds for a fresh native “esc again to interrupt” footer, then confirms once with input locked and the same launch still working. Already-armed prompts receive only one confirming key. Other providers receive one Escape, following Orca's [terminal-backed interrupt](https://github.com/stablyai/orca/blob/main/src/main/runtime/terminal-agent-interrupt.ts). It never retries a write, kills the process or assigns an outcome; native evidence still determines the resulting status. Unfocused prompts or custom keybindings require inspection in Terminal. Narrow agent headers hide secondary identity/model metadata, and overlay close controls remain anchored to their header's top-right corner. Markdown view choices use accessible icon controls.

Opening Chat performs the same initial terminal read and one-time backend-lost recovery as Terminal mode, with shared in-flight recovery across mounts. Intentionally exited agent processes remain stopped and expose explicit Resume/Open Terminal actions. Recovery never replays input or depends on mounting xterm.

Vade-created worktrees live under the data directory's `worktrees/<projectId>/<name>` tree. An exact discovered worktree there is editable; this exception applies only inside that worktree. Registry files and sibling runtime directories remain inaccessible. Explorer errors use the standard alert surface with a separate retry action.

Directory metadata shares bounded Git status and root discovery reads. Name searches share a short-lived bounded ripgrep file index; content searches use fixed ripgrep JSON output with bounded time/output and native regex handling. The filesystem fallback is bounded and explicitly refuses regex without ripgrep. User globs cannot override final exclusions for private/runtime/Git data. The renderer preserves cached directories on folder expansion and has bounded source-file reopen caching. Git HEAD content is requested only for diff view. These reduce waits; they do not establish a performance comparison with another application.

Explorer discovers roots independently of provider snapshots and prefetches the root listing while the sidebar is hidden. A bounded metadata cache paints warm trees immediately after remount; active polling and manual refresh update them. Names/Contents reuses the Agent Settings two-choice control, including its colors and reduced-motion behavior.

Monaco handles source editing and editable Git diffs. Added/removed totals come from Monaco's computed line changes and update while editing. Noninteractive compact hover wrappers do not intercept Find controls. Diagnostics are off because independent files have no full project context. Cursor and undo state survive split/source/diff switches. The shared General preference controls idle and blur saves. Tiptap handles standard Markdown without rewriting it on load; edits preserve the file's newline convention, trailing newline and BOM. Embedded HTML/frontmatter and large documents use source editing. Image references remain inert rather than triggering external requests from file content.

Uses the same Lucide icon families and light/dark M/U colors, adapted to Vade's existing UI components and standalone ownership boundaries. No Orca runtime dependency.
