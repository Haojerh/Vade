# Explorer and editor

The standalone file APIs accept only a registered project and discovered worktree ID. File paths are relative, bounded, checked component by component and cannot resolve through symlinks, outside the worktree, into Git metadata or Vade's private registry. Reads are bounded UTF-8 text; saves compare the current byte hash immediately before atomic replacement and return the hash of the bytes just written. An uncertain save is never retried automatically. Fixed app-opening targets cannot carry executables or flags from HTTP.

Vade-created worktrees live under the data directory's `worktrees/<projectId>/<name>` tree. An exact discovered worktree there is editable; this exception applies only inside that worktree. Registry files and sibling runtime directories remain inaccessible. Explorer errors use the standard alert surface with a separate retry action.

Directory metadata shares bounded Git status and root discovery reads. Name searches share a short-lived bounded ripgrep file index; content searches use fixed ripgrep JSON output with bounded time/output and native regex handling. The filesystem fallback is bounded and explicitly refuses regex without ripgrep. User globs cannot override final exclusions for private/runtime/Git data. The renderer preserves cached directories on folder expansion and has bounded source-file reopen caching. Git HEAD content is requested only for diff view. These reduce waits; they do not establish a performance comparison with another application.

Explorer discovers roots independently of provider snapshots and prefetches the root listing while the sidebar is hidden. A bounded metadata cache paints warm trees immediately after remount; active polling and manual refresh update them. Names/Contents reuses the Agent Settings two-choice control, including its colors and reduced-motion behavior.

Monaco handles source editing and editable Git diffs. Added/removed totals come from Monaco's computed line changes and update while editing. Noninteractive compact hover wrappers do not intercept Find controls. Diagnostics are off because independent files have no full project context. Cursor and undo state survive split/source/diff switches. The shared General preference controls idle and blur saves. Tiptap handles standard Markdown without rewriting it on load; edits preserve the file's newline convention, trailing newline and BOM. Embedded HTML/frontmatter and large documents use source editing. Image references remain inert rather than triggering external requests from file content.

Visual/interaction references: Orca's [file icon mapping](https://github.com/stablyai/orca/blob/main/src/renderer/src/lib/file-type-icons.ts), [Git status palette](https://github.com/stablyai/orca/blob/main/src/renderer/src/assets/main.css), [rich Markdown styles](https://github.com/stablyai/orca/blob/main/src/renderer/src/assets/rich-markdown-editor.css), and [Monaco behavior](https://github.com/stablyai/orca/blob/main/docs/site/content/docs/editing/monaco.mdx). Uses the same Lucide icon families and light/dark M/U colors, adapted to Vade's existing UI components and standalone ownership boundaries. No Orca runtime dependency.
