## Chat composer

- Add a `/` reference menu that lists Chat commands and the personal skills installed in `~/.agents/skills`. Codex accepts `/` and `$` and always inserts skills as `$name`. Choosing a skill only inserts the provider-native reference; Vade never runs it.
- `/context` opens the context card, `/model` and `/effort` open the shared picker and highlight the matching section, and `/compact` asks the provider to compact the conversation.
- `/compact` sends the provider's own native compaction command to the exact idle owned terminal and reports success only after a fresh native acknowledgement. Claude, Codex, CodeBuddy, Antigravity, OpenCode, OpenCode 2, Kilo and DeepSeek Harness are supported; other providers never receive a guessed command.

## Native Chat

- Show recorded images above the prompt text as fixed-size square thumbnails with a light border.
- Project recorded images for every provider that records them, including staged path references, and keep them served from exact recorded bytes.
- Keep settled round activity bound to the turn it belongs to, so a resumed session's rounds from another day cannot fold an older conversation.
- Confirm Claude model and effort changes from a fresh native acknowledgement, and require the acknowledged model to match the request.

## Context usage

- Claude capacity now follows the auto-compact window the session actually runs under: the denominator of a native `/context` report, or the CLI's own configured `autoCompactWindow` for the measured model when `/context` has not been run. A `[1m]` model label no longer substitutes the model's raw window, and a session without any configured threshold keeps an explicit unknown capacity.
- Fall back to the newest measured request for the same model when the latest Kilo or CodeBuddy request was aborted or reported no tokens.
