## Native subagents

- Show the child agents a provider harness records for a session, above the composer and under the agent card in Workflow Topology. Codex child rollouts, OpenCode/OpenCode 2/Kilo child sessions, Claude `subagents/` transcripts, CodeBuddy `agent-*` sessions and DSH `parentSession` children are read from the provider's own records; Antigravity records none and shows nothing.
- Open a child's own public turns and recorded tool calls in the same thread, grouping and bubble styles as Native Chat, with older-history paging. A provider that keeps no separate child transcript says so instead of rendering an empty conversation. Child agents have no terminal, so no Terminal view is offered.
- Hovering a child card previews that child's newest reply rather than its parent's, and a child's state is re-read from the provider instead of being inferred from transcript growth.
- Discovery stays bounded and read-only: at most 50 children per session, 8-second cache, 1 MiB per transcript page, and opaque child IDs so no transcript path reaches the browser.

## Workflow

- A workflow identity lease now binds the participant session rather than one process incarnation. A worker terminal that was relaunched or recovered keeps its assignment and can report its result, while a stopped terminal still never inherits one. Previously any relaunch permanently invalidated every identity in the run and the only escape was cancelling it.
